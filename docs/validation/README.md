# SenseBook validation

An independent desk check of the SenseBook plan: the product, its use cases, the market, the numbers and the hard questions. It ends with a kit for testing the plan cheaply in the real world.

**Status:** desk research, November 2026. Nobody has been interviewed and no hardware has been tested. Every finding comes from published sources (listed with dates in the report) or from re-working the plan's own model. Treat it as a list of hypotheses to test, not as results.
