SenseBook hardware v2

The same clip-on head at the top edge of the book, the same size, with new insides: four 50 MP cameras, a light that lights only the page, more battery, an RK3576 computer, Wi-Fi 6 and Bluetooth 5.4, better sound, and two button layouts. Everything here comes from one 3D model and its checks.
